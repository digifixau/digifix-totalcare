What it does

Four jobs, done on a schedule, without you.

Install it once, connect your storage, and TotalCare looks after the routine work. Everything it does is logged and reported.

Backups to your own storage

Amazon S3, Cloudflare R2, Wasabi, DigitalOcean Spaces, MinIO or any S3-compatible service. A full backup weekly and only the changed files in between.

Safe updates

Plugins, themes and WordPress core, one item at a time, with a health check after each. Anything that breaks the site is rolled back automatically.

Malware scans

Runs Wordfence scans on TotalCare's own schedule and alerts you straight away when serious issues are found.

Reports

A dashboard and activity log in wp-admin, email alerts and summaries, a monthly client report as a PDF, and a signed webhook for your tools.

Backups & restores

Small daily backups. Restores that put back only what changed.

Backups

  • Weekly full, daily incremental. Only changed files are uploaded between full backups. The database is saved in full every time.
  • Your retention rules. Keep the newest N, plus daily, weekly and monthly copies. Pinned backups are never deleted.
  • Built for cheap shared hosting. Memory use stays flat however big the site is, and only about 16 MB of disk is used while a backup runs.
  • No lock-in. Archives are ordinary .tar.gz and .sql.gz files you can open with any tool.

Restores

  • All of it, or just part. The database, plugins, themes, uploads or a single folder.
  • Same site, fresh install or a new domain. URLs and paths are rewritten everywhere, including serialised data, and a different table prefix is handled.
  • The site stays online. The database is imported into temporary tables, then swapped in at once.
  • Works even when a plugin is broken. Restores run before other plugins load.

One full backup, then about 9 MB a day for a site with 27,000 files.

How safe updates work

Every update gets a safety net.

Updates run on a schedule you choose. TotalCare checks the site after every single item, so one bad release never takes the rest down with it.

  1. Back up first

    A backup is taken before anything changes.

  2. One item at a time

    Each plugin, theme or core update is installed on its own.

  3. Health check

    The site is checked after every item.

  4. Roll back if broken

    The previous copy goes back in, and that version is skipped until a newer one is released.

  5. Report

    You get an email. If the site is still broken, it's restored from the pre-run backup first.

The guardian. A small must-use plugin that loads before everything else. If a PHP fatal error stops every request, it swaps the previous version back on the very next request, so TotalCare can repair a site that can't even load its admin.

For agencies & freelancers

Look after every client site the same way.

One bucket for all your sites

Each site gets its own folder. Every folder knows which site owns it, so a staging copy can never overwrite or prune the live site's backups.

Move sites between domains

Install TotalCare on the new site, point it at the same bucket, and restore from Other sites in this bucket. URLs, paths and table prefix are adjusted for you.

Client-ready reporting

Failure alerts and summaries go to you and, if you choose, to your client. A monthly report is ready as a PDF or a printable page.

Nothing hidden

Your storage only

No tracking

Exactly what it adds

  • Two database tables (job queue and activity log)
  • Two folders in wp-content
  • The guardian must-use plugin
  • A short .htaccess rule for LiteSpeed

Deleting the plugin removes all of it. Your backups in storage are never touched.

Get started

Up and running in four steps.

  1. Install and activateUpload the zip under Plugins → Add New → Upload Plugin. TotalCare appears in the sidebar.
  2. Connect your storageUnder TotalCare → Settings → Remote storage, enter your bucket details. Saving tests upload, download, list and delete with a small file.
  3. Check the schedulesSet when backups, updates and scans run, and who should get the reports.
  4. Add a real cron job (recommended)WP-Cron only runs when the site gets visitors. Call wp-cron.php every minute from your host, then use "Test background requests" in Settings to confirm your host lets work finish.

Requirements

  • WordPress 6.2+ and PHP 7.4+
  • A single-site install (not multisite)
  • MySQL or MariaDB through mysqli
  • A bucket on any S3-compatible service
  • The free Wordfence plugin, for malware scans only

Works on shared hosts including Hostinger and LiteSpeed servers.

FAQ

Questions, answered.

Do I need Wordfence?

Only for malware scans. Backups, restores, safe updates and reports all work without it.

Where are my backups stored?

Only in the bucket you configure: Amazon S3, Cloudflare R2 or another S3-compatible service. TotalCare doesn't run a storage service of its own and keeps no local copies of backups.

What happens if an update breaks my site?

The update is rolled back straight away from a copy of the plugin or theme taken just before. If a PHP fatal error stops every request, the guardian swaps the copy back on the next request. If the site is still broken after the run, TotalCare restores the database and code from the backup taken before the run, and emails you.

Can I move a site to a new domain with it?

Yes. Install WordPress and TotalCare on the new site, enter the same bucket details, then go to Backups → Other sites in this bucket and restore the old site's latest backup. URLs, paths and the table prefix are adjusted for you. Afterwards you log in with the old site's users.

Can a staging copy overwrite my live site's backups?

No. Each backup folder records which site owns it, and a site with a different address refuses to write to or prune that folder. After a real domain change, use Backups → Take over this folder.

Does it work on LiteSpeed or Hostinger?

Yes. TotalCare was built for shared hosting and adds the LiteSpeed rule that background requests need. Use the "Test background requests" button in Settings to check your host.

I'm moving from WPvivid. What happens to my old backups?

They stay where they are and can still be restored with WPvivid. TotalCare's first backup is a full one.

Does it support multisite?

No, only single-site installs.
